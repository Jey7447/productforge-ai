# ProductForge AI

Research-backed digital product opportunity discovery and creation.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth + Postgres
- Vercel AI SDK (research/AI layer follows)

## Local setup
1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Add the ProductForge Supabase project URL and publishable key.
4. Run `npm run dev`.

Never commit service-role keys or other private credentials.
